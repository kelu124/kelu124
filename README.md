### 🔊 Ultrasound hardware

> Latest stable release: **[pic0rick](https://github.com/kelu124/pic0rick/)** ⭐ 113, an rp2040-based pulse-echo acquisition board.

**In the works**

- **[ultr4rick](https://github.com/kelu124/ultr4rick)** - The higher-power successor to pic0rick: RP2350B, 60 MS/s ADC, bipolar HV pulser, 8-channel HV mux, on-board envelope detection
- **[minus](https://github.com/kelu124/minus)** - A minimal, single-channel, low-cost pulse-echo platform, designed as a conference-workshop badge (early design)
- **[wulrick](https://github.com/kelu124/wulrick)** - Side-by-side technical comparison of pic0rick and ETH Zurich's WULPUS wearable probe

**Software & libraries**

- **[pyusbus](https://github.com/kelu124/pyusbus)** ⭐ 31 - Python APIs for USB ultrasound probes
- **[us_rf_processing](https://github.com/kelu124/us_rf_processing)** ⭐ 31 - B-mode ultrasound image reconstruction from RF data
- **[openultrasoundprojects](https://github.com/kelu124/openultrasoundprojects)** ⭐ 28 - Curated collection of open-source ultrasound projects
- **[pyUProbe1](https://github.com/kelu124/pyUProbe1)** - Python library for uProbe-1 ultrasound probe acquisitions
